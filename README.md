## Projects

**[FibreSight](https://github.com/olatunji-ogundiran/fibresight)**: a verifiable AI agent that diagnoses fibre network faults the way a senior transmission engineer does. It works remotely for the NOC from alarms, performance history and in-service OTDR, writes the dispatch work order, then guides the field technician and closes a ticket only when a live reading proves the fix. Built on Meta's Muse models for the Meta Global AI Developer Hackathon (October to November 2026).

**[DWDM fault localisation](https://github.com/olatunji-ogundiran/dwdm-fault-localisation)**: an AI-agent benchmark task in the Harbor format. From six months of OCM sweeps, amplifier telemetry and a site log on a ten-span DWDM line, the agent's program must find, date, classify (macrobend or flat loss) and size every fibre fault, while SRS and logged maintenance try to fool it. Includes the line generator, reference and independent solutions, a hardened verifier and the evidence behind every design choice.
